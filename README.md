mend applies AI-written patches in four formats — unified diff, SEARCH/REPLACE blocks, V4A patches and JSON edits — to a tree of text files, all changes or none. It finds the lines each edit names even when the model drifted their whitespace or indentation, and prints what it changed or why it failed.

## Run it

```sh
node main.ts [options] [PATCH]
```
